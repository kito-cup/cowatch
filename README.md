# CoWatch — совместный просмотр видео

Комната по ссылке, синхронный просмотр для двоих (и больше), чат. Без регистрации.

## Запуск локально (2 команды)

```bash
npm install
npm start
```

Открой http://localhost:3000 → «Создать комнату» → скопируй ссылку → открой её во втором браузере/вкладке. Вставь ссылку на видео — например:

- MP4-тест: `https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4`
- HLS-тест: `https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8`
- Любое YouTube-видео (у которого автор не запретил встраивание)

## Как это работает

- **Сервер авторитетен.** Состояние воспроизведения (`mediaTime, playing, rate, version`) живёт на сервере. Клиенты шлют действия, сервер броадкастит новое состояние всем.
- **Часы синхронизируются** NTP-подобным пингом (5 замеров, медиана) — поэтому «ожидаемая позиция» считается одинаково у всех.
- **Дрейф < 1 с лечится скоростью** (±5%, на слух незаметно), > 1 с — перемоткой. Индикатор в шапке показывает расхождение в мс.
- **YouTube** играет через официальный IFrame API: контролы у него свои, действия пользователя внутри iframe детектятся и транслируются в комнату. Качество у YouTube программно не переключается — ограничение платформы.

## Деплой в интернет (Railway, ~10 минут, есть бесплатный план)

1. Залей папку в репозиторий GitHub.
2. railway.app → New Project → Deploy from GitHub repo → выбери репозиторий.
3. Railway сам увидит `npm start` и переменную `PORT`. Ничего настраивать не нужно.
4. Settings → Networking → Generate Domain → получишь `https://твоё-имя.up.railway.app`.

Альтернативы: Render.com (тоже автодеплой из GitHub), любой VPS (`node server.js` за nginx/caddy).

⚠️ Vercel/Netlify **не подойдут** — им нужны serverless-функции, а тут постоянные WebSocket-соединения.

## Просмотр с телефонов (iPhone/Android)

Смотреть с двух телефонов можно — сайт адаптивный (видео сверху, чат снизу). Особенности iOS учтены:

- **Автозапуск.** iPhone не даёт видео запускаться без касания. Если партнёр нажал play, а ваш Safari заблокировал запуск — появится кнопка «Нажмите, чтобы смотреть вместе»: одно касание, и вы догоняете комнату в нужной секунде.
- **Контролы** показываются тапом по видео (3 сек), повторный тап — пауза.
- **Полный экран** на iPhone открывается нативным плеером iOS (ограничение Safari).
- Если Safari свернули/экран погас — при возврате соединение восстановится и плеер досинхронизируется сам.

### Деплой прямо с айфона (без компьютера)

1. github.com в Safari → New repository → «uploading an existing file» → загрузи файлы проекта (можно из «Файлов» iOS, распаковав архив долгим нажатием).
2. railway.app → войти через GitHub → New Project → Deploy from GitHub repo.
3. Settings → Networking → Generate Domain → готовая ссылка, отправляй партнёру.

## Что поддерживается

| Источник | Синхронизация |
|---|---|
| MP4 / WebM / прямые ссылки | полная, свои контролы |
| HLS / .m3u8 | полная (hls.js) |
| YouTube | полная через IFrame API (контролы YouTube) |
| MKV | ❌ браузеры не декодируют контейнер MKV |
| VK Видео | ❌ embed не даёт программного управления |

## Ограничения MVP (сознательные)

- Комнаты живут в памяти сервера: рестарт сервера = комнаты сбрасываются (пустая комната умирает через 10 мин). Для продакшена — вынести в Redis (архитектура это уже предполагает).
- Управлять воспроизведением могут все в комнате — для пары это удобнее, чем права.
- Пароли комнат, история, реакции, субтитры — следующие итерации (см. watch-together-design.md).

## Структура

```
server.js            — Express + Socket.IO: комнаты, авторитетный state, чат
public/index.html    — главная
public/room.html     — комната
public/players.js    — адаптеры источников (HTML5/HLS, YouTube)
public/sync.js       — clock sync + drift-коррекция
public/room.js       — UI комнаты, чат, хоткеи
public/style.css     — дизайн-токены
```
